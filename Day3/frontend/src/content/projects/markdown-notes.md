## Идея

Минималистичный редактор: пишешь слева, справа — предпросмотр. Заметки группируются тегами.

## Технически

1. Разбор Markdown и очистка HTML от опасных тегов.
2. Индекс для поиска строится инкрементально.
3. Горячие клавиши для всех основных действий: `Ctrl+K` — поиск.
