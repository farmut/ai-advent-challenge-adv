# AUDIT — инструкции независимого аудитора данных Day8 (стадия Executing)

Рабочий каталог: Day8. Python: `../Day6/.venv/bin/python -I`. Модели не запускать. Данные НЕ править — только отчёт.

Контекст: LoRA-тюнинг Qwen2.5-7B на смешанном train (формат Day7, факты выдуманного регламента компании
«Вереснянка Лабс», стиль ответов). Главный урок Day7: лексическая проверка пропустила 54/60 смысловых утечек
eval↔train. Схема — gen/SCHEMA.md.

## Выход
`data/audit.json` — объект `{id: {"status": "OK|LEAK|BAD_GOLD|AMBIGUOUS", "why": "..."}}` для КАЖДОЙ строки eval
перечисленных наборов, плюс поле `"_summary"`. В `why` для LEAK указывать id train-строки, с которой утечка.

## 1. Факты
`data/facts/eval_gen.jsonl` (110) против `data/facts/train.jsonl` (150), `valid.jsonl` (30), `facts/regulation.json`.
- LEAK (strata b, c, d): eval-вопрос по смыслу и рамке совпадает с train-вопросом того же факта (тот же
  сценарий/ситуация, та же синтаксическая рамка, отличие только в словах). Перефраз того же факта — цель, это не
  утечка; утечка — когда вопрос по сути повторяет обучающий. Для c: применение/композиция не должно встречаться в
  train как готовый ответ (например, train-ответ уже содержит вычисленное значение).
- BAD_GOLD: answer_keys не соответствуют регламенту, вычисление неверно, ключ ловит заведомо неверные ответы или
  не ловит естественный верный ответ (скорер `core/text.keys_match`: числа/время с цифровыми границами, «6:00» не
  совпадёт с «16:00»; буквенная альтернатива — с начала слова).
- AMBIGUOUS: вопрос допускает несколько разумных ответов или требует допущений, которых нет в регламенте.
- control: control-факты (F31–F40) и их значения не встречаются в train/valid (ни прямо, ни косвенно выводимо).

## 2. Стиль
`data/style/eval.jsonl` (40) против `data/style/train.jsonl` и `valid.jsonl`. LEAK — вопрос по смыслу повторяет
train-вопрос (та же проблема и совет), даже если topic_id другой.

## 3. Формат
`data/format/eval.jsonl` (57) прошёл два аудита в Day7 — не перепроверять, только подтвердить 57 строк.

## 4. OOD и dissimilar
`data/ood/eval.jsonl` (100) и `data/dissimilar/eval.jsonl` (32): только gold (BAD_GOLD/AMBIGUOUS) — арифметику
пересчитать, knowledge-ключи, однозначность; утечки не искать.

## Метод
Сначала прочитать все файлы целиком, затем сравнивать попарно по факту/теме. Ключи проверять реальным скорером
(`core.text.keys_match`, `is_refusal`) на естественных верных и неверных ответах. Строго, но конкретно.
