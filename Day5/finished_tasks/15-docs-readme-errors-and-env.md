# 15. Документация: README «Ошибки и ответы» + комментарии в .env.example

**Тип:** docs
**Код:** `Day5/src`
**Где:** `README.md`, `.env.example`

## Сейчас
- README не описывает, что пользователь видит при ошибках и что попадает в лог. Чтобы это узнать, нужно
  читать `handler.go`, `messages.go` и `openweather/client.go`.
- `.env.example` — пять пустых строк без пояснений: неясно, какие переменные обязательны и какие значения допустимы.

## Критерии «сделано»
- [ ] В README раздел «Ошибки и ответы» — таблица с колонками: ситуация → ответ OpenWeatherMap/Telegram →
      доменная ошибка → текст пользователю → уровень лога. Строки: невалидный город, город не найден (404),
      неверный ключ (401), лимит провайдера (429), 5xx/таймаут, слишком частые запросы, Telegram 401/404
      (бот завершается), Telegram 429 (ожидание `retry_after`).
- [ ] Каждая строка таблицы сверена с кодом (тексты сообщений совпадают с `messages.go` дословно).
- [ ] В `.env.example` над каждой переменной комментарий: обязательна или нет, значение по умолчанию,
      допустимые значения/формат (для токена — `<digits>:<secret>`).
- [ ] `make run` с заполненным `.env.example` (скопированным в `.env`) по-прежнему подхватывает переменные
      (комментарии `#` не ломают `. ./.env`).
- [ ] Код Go не изменён.
