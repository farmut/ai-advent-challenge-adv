# 06. Фича: «штиль» вместо «Ветер 0 м/с, С»

**Тип:** feature
**Код:** `Day5/src`
**Где:** `internal/delivery/telegram/format.go:25` (`formatWeather`)

## Сейчас
При скорости ветра < 0.5 м/с бот пишет `💨 Ветер 0 м/с, С`. Направление при нулевом ветре бессмысленно
(OpenWeatherMap присылает `deg: 0`), и пользователь видит «северный ветер».

## Нужно
Если `math.Round(WindSpeed) == 0`, строка ветра — `💨 Штиль`.

## Критерии «сделано»
- [ ] `WindSpeed` = 0 и 0.4 → строка `💨 Штиль`, без направления.
- [ ] `WindSpeed` = 0.5 → `💨 Ветер 1 м/с, <румб>` (граница округления покрыта тестом).
- [ ] Остальные строки ответа не изменились (`TestFormatWeather` зелёный без правок ожидаемого текста для
      ненулевого ветра).
- [ ] `go test -race ./...`, `go vet ./...`, `gofmt -l .` — чисто.
