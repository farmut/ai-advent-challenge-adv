# 08. Фича: переменная LOG_FORMAT (json | text)

**Тип:** feature
**Код:** `Day5/src`
**Где:** `internal/config/config.go`, `cmd/weatherbot/main.go:33`

## Сейчас
Логи всегда JSON (`slog.NewJSONHandler`). Для локальной отладки читать неудобно.

## Нужно
Новая необязательная переменная `LOG_FORMAT`: `json` (по умолчанию) или `text` (`slog.NewTextHandler`).

## Критерии «сделано»
- [ ] `Config` получает поле формата логов; `Load` валидирует значение без учёта регистра.
- [ ] Неизвестное значение (`xml`) → ошибка `LOG_FORMAT: ...`, которая выводится вместе с остальными ошибками
      конфигурации (через `errors.Join`, как сейчас).
- [ ] Пустое значение / переменная не задана → `json`.
- [ ] Тесты в `config_test.go`: дефолт, `text`, `TEXT`, невалидное значение.
- [ ] `main.go` выбирает handler по конфигу.
- [ ] Переменная добавлена в README (таблица «Переменные окружения») и в `.env.example`.
- [ ] `go test -race ./...`, `go vet ./...`, `gofmt -l .` — чисто.
